# Mon Trajet en Portugais (Brésil) — « PortB »

App iOS (Capacitor) 100 % audio pour apprendre le portugais du Brésil en conduisant, en courant ou en marchant. Dupliquée depuis « Mon Trajet en Allemand ».

- Nom App Store : `Portugais Brésilien Mon Trajet`
- Bundle ID : `com.tonstudio.montrajet.portb`
- RevenueCat : projet `Mon Trajet PortB`, produit `version_complete_portb`, entitlement `mon_trajet_portb_pro`
- Codemagic : profil de provisionnement `mon_trajet_portb_app_store` + certificat partagé `iOS Distribution`
- Contenu : `www/js/data.js` — 3 niveaux × 3 modules × 20 leçons × 10 phrases (champ `pt`, TTS `pt-BR`)

Voir le playbook « publication nouvelle langue » dans le projet Claude pour la procédure complète.
